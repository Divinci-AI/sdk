## Bring your coding agent

Building with Divinci in **Claude Code, Cursor, Gemini CLI, or Grok**? Install
the **Divinci Agent Skill** — a drop-in package that teaches your agent the
CLI, SDKs, and API (auth patterns, RAG ingestion, releases, the footguns) —
and connect the hosted MCP server for live access to your account:

```bash
claude mcp add divinci --transport http https://mcp.divinci.app/mcp
```

## Quick Example

```typescript
import { DivinciClient } from "@divinci-ai/client";

const client = new DivinciClient({
  releaseId: "rel_abc123",
  apiKey: "divinci_key_...",
});

// Open a thread, then stream a response token-by-token
const thread = await client.chat.create();

await client.chat.stream(thread.id, "Tell me about AI", {
  assistantName: "your-assistant-id", // the release's assistant/model id
  onChunk: (text) => process.stdout.write(text),
  onComplete: (message) => console.log("\n\nDone:", message.id),
});
```
