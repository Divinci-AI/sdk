## Keeping in sync

**Knowledge (assistant RAG):** once the Release is published, do **not** use
`divinci docs sync` / `divinci rag crawl` against its live vector — writes are
rejected by `isVectorUsed()` with a silent HTTP 200 + `failedChunkSources`
entry. Use the web_crawl connector with swap instead:

```bash
divinci connectors web-crawl "https://your-docs.example.com/sitemap-index.xml" \
  --workspace <whitelabelId> \
  --vector <liveVectorId> \
  --feed --swap --recurring
```

`--swap` crawls into a draft and repoints the Release on success; `--recurring`
enables the daily autoSync schedule. `divinci docs sync` is report-only (lists
changed pages); it never re-ingests.

**Site deploy:** `.github/workflows/divinci-docs-sync.yml` rebuilds + redeploys
on push. Set repo secret `CLOUDFLARE_API_TOKEN` and vars `DIVINCI_RELEASE_ID` /
`DIVINCI_API_URL`.
